## Frozen focal-selection rule

- **direct_targets:** Each changed conventional pytest module whose basename matches test*.py is a whole-module collector target. A nonconventional changed artifact is a direct target only if pytest itself collects one or more items when it is passed explicitly. conftest.py, package initializers, typing fixtures, and golden/support outputs that yield no pytest items are recorded as unmapped support paths, not silently called focal tests.
- **overlay_collection:** Apply the complete side-i test patch to B and collect every direct target with plugin autoload disabled. Missing conventional modules, collection errors, or zero collected items reject the side.
- **node_ids:** The sorted unique direct collector targets (normally changed test-module paths) are the frozen focal node ids. Collected leaf item ids are evidence recorded separately for each state, not a replacement target set.
- **base_collection:** Every frozen collector target must exist and collect at least one item at untouched B. A missing target, collection error, or zero-item result rejects the side. Added leaf tests inside an existing module remain included in red/green runs because the module target is unchanged.
- **no_outcome_adaptation:** No direct target is removed because of a collection or test outcome. Every non-direct test-patch path and its mapping status remains recorded.

`focal_node_ids` are the sorted, frozen collector targets (normally whole changed pytest modules). Collected overlay leaf IDs are separate evidence. A target missing or noncollecting at untouched B rejects the side; no target is dropped in response to an outcome.
